# Geospatial Data Analysis Lab: Steel Plants

## Overview
This project explores global steel plant data using two main components:
- **Jupyter Notebook (`geospatial_steel_plants.ipynb`)**: For data cleaning, exploratory analysis, geospatial visualization, and merging with environmental datasets.
- **Streamlit Dashboard (`dashboard.py`)**: An interactive web dashboard for exploring steel plant data by company, country, region, and capacity.

---

## Installation

To execute the lab (notebook and dashboard), install the following Python libraries:

```bash
pip install pandas numpy matplotlib seaborn plotly geopandas dask-geopandas shapely dask h5py streamlit pydeck
```

**Required libraries:**
- pandas
- numpy
- matplotlib
- seaborn
- plotly

- dask-geopandas
- shapely
- dask

Some libraries (like `geopandas`, `dask-geopandas`, and `pydeck`) may require additional system dependencies for geospatial operations. Refer to their documentation if you encounter installation issues.

## 1. Jupyter Notebook: `geospatial_steel_plants.ipynb`

### Purpose
- Provides a step-by-step workflow for analyzing the Global Steel Plants dataset.
- Covers data loading, cleaning, exploratory data analysis, geospatial mapping, integration with environmental data, and summary statistics.

### Main Steps
- **Data Loading & Cleaning**: Merges multiple Excel sheets, removes unnecessary columns, imputes missing values, and converts coordinates.
- **Exploratory Data Analysis**: Summarizes plant counts, capacity, geographic distribution, and company/region breakdowns.
- **Geospatial Visualization**: Uses Plotly to create interactive maps (scatter, size by capacity, density heatmap) of plant locations.
- **Environmental Data Integration**: Loads external environmental datasets (LitPop), performs spatial joins to associate plants with nearby environmental indicators.
- **Output**: Saves a cleaned CSV (`steel_plants.csv`) for dashboard use.

### Usage
Open the notebook and execute cells sequentially. Modify file paths as needed if running in a different environment.

---

## 2. Streamlit Dashboard: `dashboard.py`

### Purpose
- Provides an interactive dashboard for exploring global steel plant assets, focusing on capacity, location, and ownership.
- Enables filtering and visualization of the dataset without coding.

### Features
- **Data Filters**: Sidebar filters for company, country, and steel capacity range.
- **KPIs**: Displays total plants, total/average capacity, and number of countries.
- **Interactive Map**: Visualizes plant locations, with circle size proportional to capacity and color by region.
- **Detailed Data Table**: Shows filtered plant details including name, owner, country, region, capacity, start date, and workforce size.
- **Notes**: Sidebar explains data sources, filtering, and capacity calculation details.

### Usage
1. Ensure the cleaned dataset (`Output_dataset/steel_plants.csv`) exists (generated by the notebook).
2. Run the dashboard with:
   ```bash
   streamlit run dashboard.py
   ```
3. Use sidebar filters to explore the data interactively.
